# PumpkinCheat Updates

This public repository contains **release metadata and installable APK releases only**.
The application source code remains in the private repository.

## Update channel
- Metadata: `update.json`
- APK: attached to a GitHub Release
- Android installation is always confirmed by the Android package installer.

## Security
- No GitHub access token or other secret is stored in the APK.
- The app checks this repository's public metadata over HTTPS.
- Releases must be built from the private source repository and published by the maintainer.
